# Prompts

`primer.md` is the rules primer a Claude Agent reads in its system prompt, drafted from the Comprehensive Rules (https://rules.fabtcg.com/en/cr/) and reviewed once by the owner.

It stays byte-identical across Games so that Games played weeks apart are comparable and Claude Code's prompt cache is reused. Changing it is a deliberate decision: record the change and its reason in the Phase report.
