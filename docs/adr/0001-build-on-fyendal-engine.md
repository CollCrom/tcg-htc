# Build on fyendal.net's engine rather than our own

v1 wrote its own rules engine, and implementing every card by hand was too slow and too buggy. We now vendor fyendal.net's engine (GPL-3.0, pinned as a git submodule of upstream) and keep our own work to the layers around it. The engine suits Agents because it lists every legal Intent for a Seat, projects a hidden-information View per Seat, and is seeded and pure, so any Game replays exactly from its seed and Intents. Keeping Agents lightweight is our job, done in how we render Views, not the engine's.

## Considered Options

- **Talishar**: the engine people play online, with near-complete card coverage, but it's a PHP web server with a database and isn't built to run headless or to list legal choices.
- **Our own engine again**, with card scripts generated by an LLM from card text: this brings back the bug tail that ended v1.

## Consequences

- The project is GPL-3.0.
- Upstream's `CON.json` can't exist on a Windows filesystem, so development happens in WSL.
- Cards the engine hasn't implemented (about 17%) can't be played until upstream adds them.
